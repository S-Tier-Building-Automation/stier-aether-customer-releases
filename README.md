# S-Tier Aether 2.0 Customer Releases

This public repository is the customer update feed for S-Tier Aether 2.0.

It contains approved customer release assets only. Source code, internal runtime packages, pilot workspace packages, and private project data remain in the private S-Tier Aether repository.

Customer app packages read this repository from `STierAether.release.json` and use GitHub Releases to discover and stage updates.
